## NULL / HOME

A procedural, first-person dimensional horror game. Explore the binary-coded corridor, find three unstable anchors, and use your chrono-patcher to flip bits until each signal matches its required sequence. Then find the exit and return to your own dimension.

### Play

Open `index.html` from a local static web server (for example, `python3 -m http.server 3002`) and visit `http://localhost:3002`.

- **WASD** to move · **Mouse** to look · **Shift** to run
- **E** to interface with nearby anchors and the exit
- Click binary digits in the watch to toggle them, then choose **Commit Patch**
- On touch devices, use the on-screen direction pad and drag the view to look

Three.js is loaded as an ES module from jsDelivr.
