Speak SPARK.

SPARK is the tiny language that runs this machine. One action takes one tick.

MOVEMove one tile forward.
TURN LEFTTurn 90° without moving.
TURN RIGHTTurn 90° the other way.
TAKEPick up an energy cell on this tile.
IF BLOCKED … ENDRun the block if a wall is ahead.
IF CELL … ENDRun the block while on a cell.
REPEAT 3 … ENDRepeat a block (1–20 times).
